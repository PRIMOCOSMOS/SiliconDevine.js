  • LLM 示例：TinyGPT 与 LLaMA-style 测试架构。
  • 上游原始实现：SAB、ISAB 与原生 LLaMA 的来源。
  • VAE：高斯参数、重参数采样及示例。
  • 特殊算子与教学机制：动态卷积、条件注意力及独立教学机制。
