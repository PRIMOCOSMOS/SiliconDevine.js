VAE 架构与可视化

使用说明 · 文档目录

启动器与网页的 VAE 栏目提供三个入口：

示例 来源 前向结构
VAE · PyTorch 官方原型 pytorch/examples 的原始 VAE 类 784 → 400 → 两个 20 维高斯参数头 → z → 400 → 784
卷积 VAE 本项目的小尺寸示例，非官方模型 Conv2d → 特征展平 → μ/logvar → z → 全连接投影 → ConvTranspose2d
条件 VAE 本项目的小尺寸示例，非官方模型 输入与条件拼接 → 编码器 → μ/logvar → z 与同一条件拼接 → 解码器

官方源码固定在提交 acc295dc7b90714f1bf47f06004fc19a7fe235c4，保存在 examples/upstream/pytorch_vae/main.py，同时保留许可证和 SHA256。适配器只通过 AST 提取并执行原始 VAE 类，不修改它的 __init__ 或 forward，不执行下载数据或训练脚本。输入是明确的合成张量，权重随机初始化，不代表训练效果。

读取真实 PyTorch 模型

from silicondevine import show
from vae_models import build_official_vae

spec = build_official_vae()
show(spec['model'], spec['args'], backend='export')

也可以在启动器中选择自己的模型文件；框架不依赖模型的类名含有 VAE。检测到实际计算图中的 mu + exp(0.5 * logvar) * randn_like(...)、匹配的形状与标准正态来源后，才赋予「高斯重参数采样」功能语义。识别兼容乘法操作数交换、FX 与 export 捕获，也兼容不导出数值的结构图。不会把 exp(logvar) 误认成同样的对数方差参数化。

解释与层级

两个参数头保持同一层级；水晶元素具有真实张量索引、形状和已捕获数值。总览将高斯采样聚合成一个完整功能单元，点击可进入原始五个算子：半对数方差、指数、标准噪声、缩放、平移。切换「算子细节」也可检查全部原始计算，支持返回。

标准正态算子输入只提供形状，不被错误地描绘成由输入数值确定的变换。噪声 ε 是本次 PyTorch 执行得到的样本；浏览器不会重新生成随机数。每个坐标的结果满足 z = mu + sigma * epsilon。

高斯曲线在 N(0,1) 和当前坐标的 N(μ,σ²) 之间平滑变换，晶体标记跟随同一个捕获的 ε。曲线是解析参考曲线，按峰值归一化显示以突出宽度变化，不是直方图，也不代表重新抽样。状态栏展示当前坐标、μ、σ、ε 和 z。动效仅在活动模块区域更新，图形对象复用；原有张量窗口与复杂图分区预算保留。

数学讲解使用 KaTeX。重建损失与 KL 正则是理论说明；当前框架捕获 eval 模式的实际前向路径，没有凭空添加反向图、训练损失节点或未执行分支。对于不同参数化、离散 VAE、向量量化 VAE 和任意分布组合，不宣称已自动识别；未匹配部分保持原始算子与真实边界。

验证

tests/test_vae.py 验证官方源文件校验和、三个模型的真实前向输出、随机状态不被导出污染、无数值导出的识别和反例拒绝。tests/vae.mjs 检查有限窗口内可计算的标量值、依赖坐标与总览/细节结构；tests/browser-v05.mjs 检查真实样本动效、返回、演示模式、移动端和减少动态效果。
