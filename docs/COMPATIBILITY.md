# 兼容性与运行边界

| 组件 | 范围 | 验证方式 |
| --- | --- | --- |
| JavaScript | ESM；Node 22.12+ | 锁文件安装、类型检查、生产构建 |
| 浏览器 | 支持 WebGL2 的现代 Chromium / Edge | Playwright 主回归；Firefox / Safari 尚未验证 |
| Python | 声明 Python 3.10+、PyTorch 2.6+ | 本地 Python 3.13.5 / PyTorch 2.9 CPU；CI 固定 PyTorch 2.9 |
| 操作系统 | Windows 桌面启动器；Python/浏览器路径适配 Windows/Linux | Windows 本机验证；Linux 由 CI 验证，尚无本次远端运行结果 |
| Transformers | 可选 4.57.1 | 官方 LLaMA / GLM 结构回归 |
| Three.js | 0.185.x | 与当前渲染实现一起验证，暂不扩大未经验证的大版本范围 |

模型导入先扫描源码，再绑定构造参数，使用 meta 设备统计参数与缓冲元素，最后分配 CPU 模型并验证示例输入。已识别的 PyTorch 通道数、特征数等整数参数会在构造前检查；只接受位置参数的构造函数也可使用命名表单配置。

无法在 meta 上构造的模型会给出专门提示，不能自动绕过内存预检。可调整构造函数，或自行构造小模型后调用 `silicondevine.show(model, args)`。预算是元素数量限制，不是整个 Python 进程的内存上限；任意 Python 代码和自定义设备分配仍需由模型作者负责。

当多个独立入口都有效时，需要确认一个入口。缺少可靠输入信息时显示结构视图；execution 后端只记录示例实际执行路径。未支持算子保留边界。不会自动加载训练权重，也不会把构造初始化值称为训练结果。

导入失败可修正指定字段，或点击“恢复自动解析”清除工作台覆盖并忽略项目旧配置；这不修改模型源码或项目配置文件。网络请求有超时和自动轮询恢复，重试请求不会重复提交，重新捕获失败保留上一份图。
