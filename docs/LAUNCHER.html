本地启动器

使用说明 · 文档目录

双击 SiliconDevine.exe。选择示例或自己的 PyTorch 模型文件，确认 Python 环境，然后点击「进入模型空间」。也可以使用 Ctrl+Enter。原来的 start-app.cmd 会优先启动 EXE。

EXE 内置启动器所需的 Python 和 Tk，启动界面不再依赖系统如何关联 .py 文件，也不会弹出命令行黑窗口。模型计算使用你选择的外部 Python / PyTorch 环境，继续支持不同 IDE 与虚拟环境。

请将 EXE 保留在 D:\SiliconDevine.js 中；它读取同目录的 python、demo-dist、examples、docs 和 launcher.ico。如需桌面入口，可以给 EXE 创建快捷方式。搬迁到其他电脑时应复制整个文件夹，并配置那台电脑的 PyTorch 环境，不能只复制 EXE。

「高级设置」包含捕获接口和工厂函数。折叠时仍显示当前值，选择示例会同步更新它们。运行期间配置锁定，停止后可以修改；IDE 中修改并保存模型代码仍然自动触发更新。

底部始终显示当前状态和主要操作。细线运动表示正在捕获，不代表完成百分比。模型就绪后自动打开浏览器，也可以再次点击「打开工作台」。运行日志按需展开；捕获失败会自动展开日志。

窗口启用了 Windows DPI 感知，在创建窗口之前配置，避免系统对整个界面进行模糊的位图放大。原生字体与布局间距使用当前缩放比例。界面已检查 100% 和 150% 的默认尺寸及窄窗口尺寸；配置区域可滚动，底部操作保持可见。

采用 Python 自带 Tk，无需额外安装界面库。关闭旧版启动器并重新打开即可使用新版；关闭窗口会停止它启动的模型服务。

重新构建

已验证构建工具为 PyInstaller 6.22.3（Windows x64）。开发者可在独立构建环境安装 pyinstaller==6.22.3，然后在项目目录运行：

python -m PyInstaller --noconfirm --distpath . --workpath .build-exe SiliconDevine.spec

不要在 EXE 正在运行时覆盖它。可执行文件包含版本信息和应用图标。desktop_entry.py 为入口，desktop_runtime.py 负责打包路径及外部 PyTorch 进程环境隔离。

需要诊断打包后的启动链路时，可执行 SiliconDevine.exe --self-test report.json。该模式在后台捕获 MLP、检查网页资源、验证浏览器交接、保存临时设置，并停止本次服务。可使用 --preset "LLaMA · Transformers" 检查原生 LLaMA，或 --python 指定解释器。正常双击不会运行此诊断。

外观与模型库

启动器采用左右双区布局：左侧是原生分辨率的动态几何品牌画面，右侧配置代码与环境；小窗口自动收起品牌画面，保留配置与主要操作。Web 默认是全幅模型舞台，底部操作台集中控制播放、缩放、标牌、速度与进度。

「模型库」是独立的分类浏览界面，包含基础网络、注意力与语言、变分自编码、集合架构，以及导入和 IDE 连接。「解读与参数」打开侧旁的说明、计算图索引、可调示例的 Batch 与通道参数、张量窗口、数值色谱和渲染信息；手机上这部分置于舞台下方。「演示模式」收起辅助界面；Escape 返回普通工作模式。

模型切换与界面展开有短时过渡；减少动态效果偏好会关闭外观动画并默认暂停计算演示。启动器遵循 Windows 客户区动画设置，隐藏品牌区域时停止其动画。几何品牌画面不表示模型数据。

模型选择新增「VAE · PyTorch 官方」「卷积 VAE」「条件 VAE」。原理、源码来源和适用边界见 VAE.md。
