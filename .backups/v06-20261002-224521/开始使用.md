# SiliconDevine 使用说明

## 先打开一个示例

1. 双击 `D:\SiliconDevine.js\SiliconDevine.exe`。
2. 在「从示例开始」中选 **MLP**。
3. 确认 Python 环境。你这台电脑已验证可用的是 `D:\Anaconda3\python.exe`。
4. 点击「进入模型空间」，稍等片刻，浏览器会自动打开。

想看 VAE，就选「VAE · PyTorch 官方」「卷积 VAE」或「条件 VAE」。也可以在网页右上角的「模型库」里切换预置模型。

请把 EXE 和同目录的文件放在一起。平时使用无需启动 Node，也无需重新构建。

## 用自己的模型

在 IDE 中新建一个 Python 文件，例如 `D:\MyModels\my_model.py`，写入：

```python
import torch
from torch import nn


def build_model():
    model = nn.Sequential(
        nn.Linear(16, 24),
        nn.GELU(),
        nn.Linear(24, 8),
    )
    inputs = (torch.randn(2, 16),)
    return model, inputs
```

这里的 `build_model()` 返回模型和一组示例输入。框架会运行一次前向计算，读取结构和张量。将 `model` 换成你的模型，并把 `inputs` 改成它实际接受的输入；使用已有权重时，在返回前加载权重。

然后在启动器中：

1. 点击「选择文件」，选中刚保存的 Python 文件。
2. 点击「选择环境」，选中安装了模型所需依赖的 `python.exe`。
3. 展开「高级设置」，工厂函数填 `build_model`。普通网络可先用 `fx`；Transformer、VAE 建议用 `export`。窗口较小时，设置区域可以滚动。
4. 点击「进入模型空间」。以后在 IDE 保存代码，网页会自动更新。

更换模型文件或 Python 环境前，先点「停止服务」。关闭启动器会停止本次服务；只关闭网页时服务继续运行。

## 怎么看模型

| 想做什么 | 操作 |
|---|---|
| 旋转、缩放 | 拖动模型；滚轮缩放，也可用底部的放大、缩小按钮 |
| 看某一块的计算 | 把鼠标停在该模块区域 |
| 深入查看 | 点击模块，或在「解读与参数」的结构索引中选择 |
| 返回 | 「上一级」返回父层；「总览」恢复当前层的整体视角 |
| 暂停、单步查看 | 底部暂停按钮和计算进度滑块 |
| 看原理、公式和张量尺寸 | 右上角「解读与参数」 |
| 改 Batch 和通道数 | 选择「可调 MLP」，打开「解读与参数」，改数值后点「更新模型」 |
| 调整自己的 PyTorch 模型尺寸 | 在 IDE 修改示例输入或网络参数并保存 |
| 放大演示区域 | 「演示模式」收起辅助界面；「全屏」进入全屏视图 |

颜色对应张量数值；「解读与参数 → 数值色谱」可以查看图例。大张量按坐标窗口显示，可在同一面板中切换窗口。

VAE 中可以查看均值、对数方差、采样潜变量和解码路径。点击采样模块能展开原始计算；曲线和晶体使用本次 PyTorch 前向计算中的实际数值。示例默认使用随机初始化权重。

## 出问题先看这里

| 情况 | 处理 |
|---|---|
| 提示找不到 torch 或其他包 | 确认选对 Python 环境，并在该环境安装缺少的包 |
| 找不到工厂函数 | 检查文件里是否有 `build_model()`，以及「高级设置」里的名称是否一致 |
| 输入形状不匹配 | 检查 `inputs` 的尺寸、数据类型和模型要求，修改后保存 |
| 捕获失败 | 打开启动器的「运行日志」看具体报错；修好并保存，框架会重试 |
| 浏览器没有自动打开 | 等状态显示已连接，再点「打开工作台」 |
| 仍看到旧界面 | 关闭旧启动器，重新打开本目录的 EXE；网页按 Ctrl+F5 刷新 |

目前主要展示前向计算。完整反向传播和所有自定义算子的内部动效还未覆盖。其他接入方式见 [IDE 接入](docs/LIVE.md)，支持范围见 [SUPPORT.md](docs/SUPPORT.md)。
